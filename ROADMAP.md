# Roadmap

## Ideas / Backlog

- `cmm rename <old-name> <new-name>` — rename a plugin and update marketplace.json
- `cmm remove <plugin-name>` — unregister a plugin from marketplace.json (with optional directory deletion)
- `cmm validate` — lint marketplace.json and all plugin.json files for schema compliance
- `cmm sync` — ensure plugin.json versions and marketplace entry versions are in sync across all local plugins
- Multi-marketplace workspace support (manage several marketplace repos from a root config)
